# Digital Signature Pad

A clean, browser-based digital signature tool. No server, no uploads — everything runs locally in your browser.

## Features

- **Draw** your signature freely using mouse or touch
- **Add a name** with 10 font options and adjustable size
- **Drag** the name text anywhere on the canvas
- **12 ink colors** to choose from
- **Adjustable pen thickness**
- **Undo** stroke by stroke
- **Download** as PNG, SVG, or JPEG
- Fully **offline** — no data is sent anywhere

## Usage

Open `signature-pad.html` in any modern browser. That's it.

## Fonts Supported

Dancing Script, Great Vibes, Pacifico, Satisfy, Caveat, Pinyon Script, Playfair Display, DM Sans, Courier Prime, Georgia

## Tech Stack

- Vanilla HTML, CSS, JavaScript
- [`signature_pad`](https://github.com/szimek/signature_pad) by Szymon Nowak (via jsDelivr CDN)
- Google Fonts (loaded via CDN)

## Browser Support

Works on all modern browsers — Chrome, Firefox, Safari, Edge — on both desktop and mobile.
